# ICT251 Activity 3 — Modern Personal Website Starter

This is a **starter project**, not a finished personal submission. Personalise it and continue from your own Activity 2 website as required by your lecturer.

## Files and folders

- `index.html` — website structure and content
- `css/styles.css` — responsive modern interface and styling
- `js/script.js` — interactive JavaScript features
- `images/` — placeholder SVG illustrations; replace them with your own photos
- `videos/` — put your own short video and audio here

## Before submission — personalise these items

1. Replace `Your Name` and the `YN` initials in `index.html`.
2. Rewrite the About Me section in your own words (at least 50 words).
3. Make sure you have three genuine hobbies and three learning-plan steps.
4. Edit the weekly study table to reflect your plan.
5. Replace `images/photo1.svg`, `photo2.svg`, and `photo3.svg` with three appropriate photos. Update the image `alt` text, captions, and gallery `data-image` filenames.
6. Add your Activity 2 media files into `videos/`. Either name them `my-video.mp4` and `my-audio.mp3`, or update the `<source src="...">` paths in `index.html`. Update the summaries.
7. Edit the three project/skill cards so they describe your own work or skills.
8. Replace the GitHub profile link in the footer with your actual profile or repository link.
9. If your Activity 2 site already exists, transfer these improvements into your own project rather than submitting this starter unchanged.

## JavaScript features

1. Contact form validation and an on-page preview (no message is sent).
2. Expand/collapse project details.
3. Search/filter projects and skills.
4. Photo gallery viewer.
5. Bonus: mobile navigation.
6. Bonus: light/dark theme toggle.

## Test locally

1. Open this folder in Visual Studio Code.
2. Install/enable the Live Server extension if available.
3. Right-click `index.html` and choose **Open with Live Server**.
4. Test navigation links, gallery, project details, search, theme toggle, and the contact form.
5. Try submitting the form with blank fields, an invalid email, and valid sample information.
6. Open browser developer tools and check the Console for errors.
7. Test a narrow mobile width (around 375px) and a wide desktop width (around 1280px).

## Publish with GitHub and Render

1. Create a GitHub repository for your project.
2. Upload the website files and folders so `index.html` is at the repository root.
3. Commit your changes.
4. In Render, create a **Static Site** and connect your GitHub repository.
5. If `index.html` is at the root, leave Root Directory blank. Use Build Command `echo "No build required"` and Publish Directory `.` if the dashboard asks for them.
6. Deploy and wait for the service to become Live.
7. Open the public `onrender.com` link and test the live site. Make one small improvement, commit it, and check that the live site updates.
8. Submit the live website URL as instructed by your lecturer.

## Important

The contact form only demonstrates front-end validation. It does not email, transmit, or store submissions. Do not add private information to the public site. Only use images, audio, and video that you have permission to publish.
